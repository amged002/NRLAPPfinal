# Security

We take security seriously. If you discover a potential security vulnerability in this repository, please report it so we can respond promptly and responsibly.

Preferred reporting methods:

- Open a private GitHub Security Advisory for this repository: https://github.com/amged002/NRLAPPfinal/security/advisories/new
- If you cannot use the private advisory flow, open an issue titled "[SECURITY] <short summary>" and mark it as private if possible. Avoid including sensitive details publicly.

What to include in a report:
- A detailed description of the issue and its impact.
- Steps to reproduce the issue (minimal proof-of-concept if available).
- Version(s) affected.
- Any suggested mitigation or workaround.

Response and timeline:
- We will acknowledge receipt within 72 hours and provide updates on remediation.

Notes:
- Do not publicly disclose the vulnerability until it has been fixed and coordinated disclosure is agreed upon.
